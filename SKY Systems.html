SKY OS · SKY UI

SKY Systems

SKY Systems 是 SKY OS 与 SKY UI 的合称：SKY OS 是面向 PC 的操作系统，SKY UI 是面向移动端的操作系统，两者各自完整独立

SKY Systems is the name for two operating systems taken together—SKY OS for PC and SKY UI for mobile. Each one is a complete system in its own right.

SKY OS 版本 v1.8.2

SKY OS

PC 操作系统 PC Operating System

面向 PC 的操作系统，提供桌面环境、多窗口管理、文件系统、应用启动器与通知中心，让应用在桌面端完整运行。

版本 v1.8.2

SKY UI

移动端操作系统 Mobile Operating System

面向移动端的操作系统，为手机与平板提供触控优先的界面体系、应用容器与交互规范，让应用在移动端自然可用。

SKY OS 与 SKY UI 各自是完整独立的系统，不是一个系统套另一个，也没有合并成一个新系统；两者合起来统一称为 SKY Systems。
