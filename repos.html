SKY OS/UI

Operating System & User Interface

v1.8.2

基于 TurboWarp 构建的桌面操作系统与用户界面，提供直观流畅的交互体验。深度整合 SKY 生态产品，为开发者打造一体化桌面工作环境。

技术特性 Technical Features

  • 基于 TurboWarp 深度定制，兼容 Scratch 生态
  • 自定义窗口管理系统，支持多任务并行操作
  • 内置文件管理器与应用启动器
  • 轻量级设计，低配置设备也可流畅运行

SKYEditor

Editor & Interpreter

v3.2.1

TurboWarp 深度定制版编辑器与解释器，专为 SKY OS/UI 应用运行优化。提供毫秒级响应速度与高效内存管理，是 SKY 生态的核心运行时引擎。

技术特性 Technical Features

  • TurboWarp 核心深度定制，性能优化提升 40%+
  • 智能内存管理，大幅降低运行时资源占用
  • 完整项目管理与调试工具链
  • 插件式扩展架构，支持第三方模块集成

SKY Code

Programming Language

v2.0.5

仿 Python 语法的专属编程语言，简洁优雅，专为 SKY 生态设计。具备强大标准库与模块化开发支持，让功能扩展轻而易举。

技术特性 Technical Features

  • 类 Python 简洁语法，零基础快速上手
  • 丰富内置标准库，覆盖文件/网络/图形等场景
  • 模块化架构，支持自定义扩展与依赖管理
  • 原生 SKYEditor 集成，编辑运行一键切换
