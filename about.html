About SKY Studio

关于 SKY Studio

一个专注国内 Scratch Mod 生态的开源团队。我们用编辑器、系统层与开发工具三条产品线，把分散在各处的改版编辑器聚到同一套生态里。

我们是谁

SKY Studio · SKY-Studio-cn

SKY Studio 以国产 Scratch 编辑器 SKYEditor（内测进行中）为核心，聚合国内各家改版编辑器的扩展与作品； 并以 SKY Systems、SKY IDE 与之共同构成开源产品矩阵。

所有项目以开源方式对外提供，代码托管在 GitHub 组织 SKY-Studio-cn，坚持公开、可复核、可再分发。

三条产品线

各自独立演进，共同服务同一套生态

SKY Systems

Systems

SKY Systems 是 SKY OS 与 SKY UI 两者的合称，两者各自是完整独立的系统，不是一个系统套另一个，也没有合并成一个新系统：SKY OS 是面向 PC 的操作系统，提供桌面环境、多窗口管理与文件系统；SKY UI 是面向移动端的操作系统，为手机与平板提供触控优先的界面体系。

查看 SKY Systems

SKY IDE

Integrated Development Environment

面向 SKY 生态的集成开发环境：编写、运行、调试、打包在同一处完成，让扩展作者有一条顺手的开发链路。

查看 SKY IDE

SKYEditor

基于 TurboWarp · GPL-3.0

国产 Scratch Mod 编辑器，基于 TurboWarp 构建，目前处于内测阶段，是整个生态的核心与入口。

前往 SKYEditor

我们在做什么

统一国内 Scratch Mod 生态

聚合而非割裂

国内改版编辑器长期各自为政：扩展不互通、作品难迁移、分发渠道分散。我们希望把扩展与作品聚到同一套工具链与分发入口下，让创作者不必在多个生态之间反复搬运。

开源与合规

全部项目开源托管，遵循上游许可（SKYEditor 基于 TurboWarp，GPL-3.0）。我们不是 Scratch 官方产品，也不冒充官方；上游的功劳始终归上游。
